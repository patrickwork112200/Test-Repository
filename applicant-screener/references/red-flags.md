# Red Flags & Authenticity Review

A red flag is a hypothesis, not a conviction. Roughly half of hiring managers
treat job-hopping alone as disqualifying, yet tenure patterns have weak
predictive validity compared to structured skill evidence — so this skill
converts flags into **probe questions** and reserves rejection for the narrow
set of critical, evidence-backed cases. Every flag you record needs three
parts: *what you saw*, *severity*, *the question that resolves it*.

## Severity levels

- **Note** — worth awareness, no action needed; appears in the report only if
  space allows.
- **Concern** — must be probed before or during the next interview stage;
  unresolved concerns on material points push the verdict toward Endorse with
  Conditions.
- **Critical** — evidence-backed integrity or feasibility problem; a standing
  critical flag is a gate failure (Do Not Endorse). "Evidence-backed" is
  load-bearing: a suspicion is at most a Concern until corroborated.

## Career-pattern flags

| Pattern | Default severity | Probe |
|---|---|---|
| 3+ consecutive stints under ~18 months (excluding contracts/layoffs, which are market-normal) | Concern | "Walk me through the moves — what prompted each?" Listen for pattern of blame vs. circumstance |
| Unexplained gap > 6 months | Concern | "What were you doing between X and Y?" Many answers are benign (care, study, visa, market); it's the *unexplained* that's the flag |
| Gap filled with vague "consulting/freelancing" and no clients or outputs | Concern | "Which clients or projects? What did you deliver?" |
| Seniority regression (title/scope moving down without stated reason) | Note→Concern | "What drew you to a smaller-scope role?" |
| Sideways drift — same role, same level, 10+ years, applying to a step-up | Note | Probe for growth evidence; not disqualifying |
| Current-role tenure < 6 months and already moving | Concern | "What's changed since you joined?" |

Contract and project-based careers legitimately produce short stints — check
whether the CV labels roles as contract before flagging. If it doesn't say,
that's the probe.

## Content-quality flags

| Pattern | Default severity | Probe |
|---|---|---|
| Responsibilities listed, zero outcomes anywhere ("responsible for managing…") | Note | Ask for one quantified result per key role |
| Achievements that are all round numbers and superlatives with no mechanism ("improved performance 300%") | Concern | "How was that measured? What did you change?" |
| Title inflation vs. described work (Director doing IC tasks) | Concern | Probe scope: team size, budget, decisions owned |
| Buzzword-dense, generic, template-uniform text (increasingly: AI-boilerplate CVs — flawless generic prose, no specifics that could only come from having been there) | Note→Concern | Depth-probe any core skill: specifics collapse fast if the CV is hollow |
| Skills section contradicts experience section (expert-listed skill appearing in no role) | Concern | "Where did you last use X in production?" |

## Consistency & fraud signals

Candidate fraud is no longer edge-case — screening firms flagged ~20%+ of 2025
applicants as potential fraud risk, and impostor interviewing (someone else
takes the call) is a real pattern in remote hiring. Signals, roughly in
ascending severity:

| Signal | Default severity |
|---|---|
| Dates that don't reconcile across CV, LinkedIn, and application form | Concern |
| Every role exactly the same length; transitions with zero gap ever | Concern |
| Contact details inconsistent with stated location; email created for the application | Concern |
| Credentials from unverifiable institutions / known diploma mills; certs that can't be looked up | Concern→Critical once checked and failed |
| Employer that can't be found *and* can't be explained (genuinely small/renamed firms exist — probe first) | Concern→Critical |
| Confirmed misrepresentation: dates, degree, cert, or role verifiably false | **Critical** |
| Interview-stage impostor indicators (voice/appearance mismatch across calls, answers read aloud, refusal of camera without cause) | **Critical** — recommend identity re-verification |

Verification recommendations belong in the report's conditions when concerns
cluster: reference checks on specific claims, certification lookups (most
major issuers have public verification portals), sequential-interviewer
identity confirmation for remote candidates.

## What is NOT a red flag

Keep the flag list honest — these are common false positives; do not report
them as flags:

- Employment gaps that are explained (caregiving, study, health, layoff,
  visa timing, deliberate break)
- Short tenures labeled as contract, internship, or acquisition
- Career changes with a stated rationale
- Non-traditional education when the JD allows equivalent experience
- Overqualification by itself — probe motivation instead ("what makes this
  role the right next step?") and let the answer speak
- Anything touching a protected characteristic — age-revealing graduation
  dates, family status, photos, accent/nationality. These are not flags at
  any severity, and the report must not mention them even neutrally.

## Reporting

The report's Risk section lists only Concern+ items (Notes may be summarized
in one line), each as: **flag → severity → probe question**. Then state the
bottom line: does any flag stand as Critical, and do the Concerns
collectively change the verdict tier or just add conditions?
